# Veritas University Student Hub
A student resource hub built for Veritas University students to easily access lecture materials, past questions, course information, useful links, departmental announcements, and academic resources all in one place.

🔗 Live site: https://chibbyy.github.io/veritas-student-hub/

# Features
- Navigation bar linking to 6 resource sections
- Lecture materials and past questions with downloadable file links
- Course information table (code, title, units, lecturer)
- Useful links to official university resources
- Departmental announcements feed
- Academic resources (external learning platforms)
- Fully responsive design (mobile-friendly)

# Built With
- HTML5
- CSS3 (Flexbox, media queries)
